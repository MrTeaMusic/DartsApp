# Eigene Spiele: Regeln

So sind deine zwei Spiele umgesetzt (seit Phase 3). Alles in **fett** ist eine Option, die du vor dem
Start einstellst.

## Drei-Treffer-Runde (Around the World mit Pflicht)

* Reihenfolge: **1 bis 20**, danach **Bull** (an/aus). Alternativ **im Uhrzeigersinn** (20, 1, 18, …)
  oder **zufällig**.
* Ziel pro Zahl: **3 Treffer** (einstellbar 1 bis 9). Single, Double und Triple zählen je als **1 Treffer**
  (Option: Double = 2, Triple = 3 Treffer; Bullseye = 2). Überzählige Treffer verfallen.
* Treffer sammeln sich **über mehrere Aufnahmen**, bis die Zahl erledigt ist.
* Jeder Dart wird gegen die Zahl gewertet, die in dem Moment aktuell ist. Wer mit dem zweiten Dart die
  dritte 5 trifft, wirft den dritten Dart schon auf die 6.
* Bull: 25 und Bullseye zählen je als 1 Treffer.
* Ende, wenn die letzte Zahl erledigt ist. Wertung: benötigte Darts (weniger ist besser).

## Around the World mit Überspringen

* Reihenfolge: **1 bis 20**, danach **Bull** (an/aus), wie oben auch umstellbar.
* **Eine Aufnahme (3 Darts) pro Zahl**, danach geht es immer weiter.
* Punkte nur für Treffer auf die aktuelle Zahl: Single = 1, Double = 2, Triple = 3.
  Bull: 25 = 1, Bullseye = 2.
* Die Aufnahme endet nach 3 Darts oder beim Takeout bzw. „Weiter“.
* Erreichst du in der Aufnahme mindestens **4 Punkte** (einstellbar 1 bis 9) (z. B. Single + Triple), wird die nächste Zahl
  übersprungen. Übersprungene Zahlen bringen 0 Punkte.
* Skip beim Wechsel zu Bull: Von der 19 aus überspringst du die 20 und landest auf Bull. Von der 20 aus
  wird Bull **nicht übersprungen** (Option: Bull darf übersprungen werden, dann endet das Spiel).
* Wertung: Gesamtpunkte und Anzahl Skips.

Falls du etwas anders meinst, sag Bescheid; meist wird daraus einfach eine weitere Option.
